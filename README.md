# مافيا – الانتقام
نشر سريع على Render.com (مجاني): ارفع المجلد إلى GitHub ← New Web Service ← Build: `npm install` ← Start: `npm start`.
تحصل على رابط https يعمل في سفاري وكروم. التشغيل المحلي: `npm install && npm start` ثم http://localhost:3000
متغيرات اختيارية: POINTS_WIN (10) و POINTS_LOSS (0) و DATA_DIR.
